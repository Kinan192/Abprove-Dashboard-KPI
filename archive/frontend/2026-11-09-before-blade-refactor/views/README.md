# View MVC Blade

`auth/login` menyediakan login bersama. `layouts/app` adalah shell tiga role; `pages/` berisi halaman berbasis konteks dari FrontendController. `components/` memuat ikon, badge, pagination, state, grafik, tab dan formulir bersama. State interaktif berada di `resources/js/pages`, akses JSON di `resources/js/lib/api.js`, dan token desain di `resources/css/app.css`. Aset dibangun oleh Vite; data aplikasi berasal dari backend. Tidak ada pemilih role demo.

Inventaris dan QA: [docs/frontend](../../docs/frontend/README.md). Acuan visual: [FigCraft](../../design/prototypes/KPI-Kinerja-UIUX.figcraft).
