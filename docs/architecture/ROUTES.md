# Routes v3

Sumber aktif `routes/web.php` (login/logout dan include) dengan `routes/web/roles.php` (halaman dan data bersama KU/KD/HC), `routes/web/hc.php` (Super HC), dan `routes/web/admin.php` (Admin). Lihat daftar endpoint melalui `php artisan route:list --except-vendor`.

Seluruh route bisnis menggunakan web/CSRF, guard Better Auth, konteks role dan schema.v2. GET HTML dirender Blade; JSON serta mutasi memerlukan domain v2 dan migration auth. GET /{unit|division|hc}/data/workspace menyediakan DTO terikat scope untuk aplikasi berakun. Tidak ada endpoint draft/start/submit parsial/publish terpisah atau finalisasi HC.

Role prefix: unit, division, hc, admin. Admin (`/admin`) memiliki `accounts` (CRUD akun, `GET /admin/data/accounts` berpaginasi), `logs` (`GET /admin/data/logs/{audit|login|email}` berpaginasi, `GET /admin/data/logs/audit/{id}`), dan `reminders` (`GET /admin/data/reminders/preview`, `POST /admin/reminders`). Super HC tidak memiliki endpoint akun. CRUD organisasi/KPI/periode berada pada hc, termasuk `GET /hc/heads/preview` + `POST /hc/heads/reassign` (ganti/pindah/tukar/lepas kepala), `POST /hc/employees/transfer-preview` + `POST /hc/employees/transfers` (mutasi staf massal), dan `GET /hc/audit` (aktivitas berpaginasi). Pengisian staf ada di unit; pengisian Kepala Unit serta approve/return/bulk staf ada di division. Profil/notifikasi tersedia pada prefix sesuai role. `GET/PUT /hc/kpi-workspace?cycle=YYYY-MM[&include_assessments=1]` melayani dokumen KPI v2 (`periods`, `patterns`, `patternAssignments`; satu pola per orang per periode, pola diterapkan wajib 100%) beserta orang eligible, jabatan, kesiapan per periode, dan KPI lama yang dapat dikonversi; baris monitoring hanya dikirim bila diminta. `GET /{unit|division|hc}/data/workspace?page=<profil>&only[]=…` hanya memuat section dan jendela bulan profil halaman.

`GET /{unit|division|hc}/data/dashboard?cycle=YYYY-MM` mengembalikan ringkasan dashboard teragregasi SQL untuk scope role (metrik + pembanding bulan lalu, ketuntasan terhadap roster bulan itu, tren 12 bulan bergulir, sebaran kategori, indikator terendah/tertinggi, tugas prioritas, jadwal periode UTC, progres per divisi/unit/staf, dan aktivitas terbaru khusus HC). Halaman dashboard merender seluruh angka dari endpoint ini, bukan dari histori assessment di workspace.

Dashboard juga mengirim `performance: { level, rows: [{ id, name, average, total }] }`: rerata nilai Final per divisi untuk Super HC, per unit untuk Kepala Divisi, dan indikator KPI terendah untuk Kepala Unit. `total` adalah jumlah hasil Final yang menjadi sampel, bukan seluruh roster. Area eligible tanpa hasil Final tetap ada dengan `average: null` dan `total: 0`; jangan mengubahnya menjadi nilai nol. Tren visual memakai rerata nilai Final saja; ketuntasan tetap tersedia dalam metrik dan tabel pendukung.
