# Kebutuhan

Acuan terbaru: [Revisi per role v1.4](REVISI-PER-ROLE-v1.4.md), mencakup prioritas pengisian, pembanding bulan lalu, jejak keputusan, cakupan KPI dalam satu divisi, pilar fleksibel serta penyederhanaan menu. UI di luar daftar revisi dipertahankan.

Koreksi UI terbaru: [tab ringkas dan warna status](../frontend/compact-tabs-status/README.md) mengungguli susunan memanjang sebelumnya. Gunakan button/tab seperti Divisi/Unit/Jabatan untuk mengurangi kepadatan. Status Belum diisi, Diajukan, Dikembalikan dan Final harus dapat dibedakan dari warna teks serta labelnya.

Acuan lanjutan: [Alur v1.3](ALUR-KPI-v1.3.md) menetapkan akun kepala, staf tanpa akun, KPI HC, tanpa Draft dan keputusan KD. [Matriks revisi UI v4](../frontend/revision-v4/README.md) mencatat arahan terbaru per role, pengelompokan menu, pagination dan laporan. Arahan terbaru ini mengungguli susunan menu pada PRD/blueprint lama; kewenangan Final tetap hanya Kepala Divisi.

[PRD v1.2](PRD-KPI-Kinerja-Revisi-v1.2.md) menjadi acuan aktif, termasuk keputusan akhir penilaian oleh Kepala Divisi. PRD v1.1 dan PDF dipertahankan sebagai riwayat; path tercetak pada PDF mencerminkan lokasi lama. Referensi DESIGN_SYSTEM dan UI_UX_BLUEPRINT di references adalah sumber awal. Arahan terbaru mengenai sidebar, role terpisah, tim dan kewenangan KD mengungguli bagian sumber yang bertentangan. Kemajuan implementasi dan keputusan OPEN dicatat pada akhir PRD v1.2 serta [DECISIONS](../backend/DECISIONS.md).
