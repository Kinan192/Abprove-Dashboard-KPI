# Kebutuhan

Acuan terbaru: [Revisi per role v1.4](REVISI-PER-ROLE-v1.4.md), mencakup prioritas pengisian, pembanding bulan lalu, jejak keputusan, cakupan KPI dalam satu divisi, pilar fleksibel serta penyederhanaan menu. UI di luar daftar revisi dipertahankan.

Gunakan tab ringkas seperti Divisi/Unit/Jabatan untuk mengurangi kepadatan. Status Belum diisi, Diajukan, Dikembalikan dan Final dibedakan melalui warna teks serta labelnya. Pembersihan source mempertahankan layout aktif.

Acuan lanjutan: [Alur v1.3](ALUR-KPI-v1.3.md) menetapkan akun kepala, staf tanpa akun, KPI HC, tanpa Draft dan keputusan KD. Arahan terbaru mengungguli susunan menu pada PRD/blueprint lama; kewenangan Final tetap hanya Kepala Divisi.

[PRD v1.2](PRD-KPI-Kinerja-Revisi-v1.2.md) melengkapi acuan kebutuhan. Referensi DESIGN_SYSTEM dan UI_UX_BLUEPRINT di `references` adalah sumber awal; arahan terbaru mengenai sidebar, role terpisah, tim dan kewenangan KD mengungguli bagian yang bertentangan. Prototype, PDF lama, dan laporan review tidak disertakan.
