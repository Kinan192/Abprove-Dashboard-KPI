ABprove – KPI Kinerja RS Awal Bros Botania (prototipe)
=====================================================

Isi folder
- ABprove_KPI_Kinerja.html : aplikasi prototipe. Buka langsung di browser (Chrome/Edge/Safari), tidak perlu internet atau instalasi.
- 0_Login                  : halaman masuk dan lupa kata sandi.
- 1_Kepala_Unit            : semua halaman untuk Kepala Unit.
- 2_Kepala_Divisi          : semua halaman untuk Kepala Divisi.
- 3_Super_HC               : semua halaman untuk Super HC, termasuk panel tambah karyawan, tambah kepala unit, Atur KPI, dan Export Excel.

Gambar diambil di layar laptop 1440 px (resolusi 1,5x), satu halaman penuh dari atas sampai bawah. Data di gambar adalah data contoh, periode November 2026.
